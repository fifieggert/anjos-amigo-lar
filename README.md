# Anjos Protetores Dashboard

Crie um protótipo moderno e responsivo de um sistema web chamado Anjos Protetores, voltado para a gestão de abrigos de animais. O sistema deve ter interface intuitiva, simples e fácil de usar, focada em usuários com pouco conhecimento técnico. O design deve transmitir cuidado, acolhimento e organização, utilizando cores suaves como azul claro, verde água, branco e detalhes em laranja.

O sistema deve possuir:

Estrutura geral

 Sidebar lateral responsiva

 Dashboard principal

 Navegação simples

 Interface clean e moderna

 Compatível com desktop, tablet e mobile

 Estilo semelhante a sistemas SaaS modernos

Telas do sistema

1. Tela de Login

 Login com e-mail e senha

 Botão “Entrar”

 Link “Esqueci minha senha”

 Logo do abrigo com tema animal

2. Dashboard

Mostrar:

 Quantidade de animais disponíveis

 Quantidade de adoções realizadas

 Estoque de doações

 Alertas de estoque baixo

 Solicitações de adoção pendentes

 Cards com estatísticas

 Gráficos simples e modernos

3. Gestão de Animais

Tela para:

 Listar animais

 Buscar por nome ou espécie

 Filtrar por status:

 Disponível

 Adotado

 Em tratamento

 Em espera

Cada card do animal deve mostrar:

 Foto

 Nome

 Espécie

 Idade

 Porte

 Status

Criar também:

 Modal ou página de cadastro de animal

 Campos:

 Nome

 Espécie

 Raça

 Idade

 Porte

 Foto

 Status

 Descrição

4. Gestão de Doações

Tela com:

 Controle de estoque

 Lista de itens doados

 Categorias:

 Ração

 Limpeza

 Brinquedos

 Quantidade disponível

 Data de entrada

 Nome do doador

 Alertas visuais de estoque baixo

 Botão para registrar entrada e saída de itens

5. Adoções

Tela para:

 Visualizar solicitações de adoção

 Aprovar ou recusar pedidos

 Mostrar:

 Nome do interessado

 Animal solicitado

 Telefone

 E-mail

 Status da solicitação

Adicionar:

 Botão “Gerar termo de adoção”

 Timeline simples do processo de adoção

6. Área Pública

Página pública sem login para visitantes:

 Lista de animais disponíveis

 Cards modernos

 Filtros por:

 Espécie

 Porte

 Idade

 Botão “Quero adotar”

7. Relatórios

Tela com:

 Relatório de animais

 Relatório de doações

 Relatório de adoções

 Exportação PDF e CSV

 Gráficos e tabelas

Regras visuais

 UI moderna estilo SaaS

 Componentes arredondados

 Sombras suaves

 Ícones minimalistas

 Muitas imagens de cães e gatos

 Aparência amigável e acessível

 Priorizar usabilidade

Extras importantes

 Simular dados reais do abrigo

 Inserir mensagens de feedback e alertas

 Criar protótipo navegável completo

Baseie o sistema em plataformas como:

 Shelterluv

 Animal Shelter Manager

 Barrk

Mas faça uma interface mais moderna, intuitiva e simplificada, focada na realidade brasileira e no controle eficiente de doações e adoções.
